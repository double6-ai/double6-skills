# 固定行内绑定候选的核验

使用同一 `numeric-and-figure-v1` 策略。依据完整实际段落及该输入的冻结字体、栏宽、字号、行距核验，不提供页码白名单、目标词串或单段坐标补丁。绑定数字型小字号片段前最多四个连续汉字，或完整相邻 Latin 片段；中文图表编号及括号文献编号按共享语法绑定。四字规则是启发式，不能称为完整中文语义词识别。

比较实际保存 PDF：全文、Unicode/GID、字体文件 SHA、字体名、字号、颜色、宿主行、真实墨迹、原框容量和链接。缺宿主、整项超框、段落绑定失败、字体/字形改变、链接尚未重绑定均停止受影响输入。停止保留失败证据；同一规则在其他输入上的收益继续报告。不得为某个 case 加例外或用其他字体代替真实字体。

采用 `actual_style_ref` 恢复原生浮点RGB时，先验证样式JSON及PDF的SHA和完整字形身份；不能把HTML的8位取整当作原RGB。按实际PDF再次测量颜色，禁止手填某个引用的颜色补丁。

成品前后截图取实际 PDF，写明比较范围和 PDF SHA。样段验证不能授予整件验收、人工接受或 strict delivery。
