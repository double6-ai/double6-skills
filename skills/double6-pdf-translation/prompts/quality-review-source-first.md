# PDF翻译独立审校提示

有限 trial-render 原生输入若声明 typography_class，核对同类全部成员及基本 source_role；类别不能改写正文身份。逐项读取保存后的 RGB、对齐、粗体及合成倾斜证据，特别检查白字图示、混色 URL、多行机构和标题居中。合成倾斜不能写成实际斜体字体；HTML/CSS 或 manifest 参数不代替实际 PDF 核验。分批渲染的物理页还须核对全部目标只出现一次、背景资产只导入一次、透明层不覆盖原图和表格线，语义审校分母仍按完整源组。

先核对冻结source、target、standard、输入范围、审校授权及资源上限。仅从完整源PDF建立可读内容、原生/扫描文字、资产、刊头/作者/页脚/空白带及结构清单；冻结源先行结论后再读生产建议和译文。逐项保护必须说明源上下文，URL、邮箱或公式旁的自然语言继续应译。

数字或事实裁决必须回到同一SHA的完整源段与实际原图。每个有风险的数字逐项写出主体、源原词/数值、单位、比较基准、时间范围及关系（实得量/缺额、百分比/百分点、每次/每分钟等），并注明页/区域/源图引用；只有可直接看清的值才能填入。没有源据、字形不清或OCR与原图冲突时记UNKNOWN，不凭常识补年份、换算数量级或推测州数。审校摘要、旧报告与其它agent的数字结论不作为金标；可用作疑点索引，但每项必须独立回源核准。确认摘要误读时保留原件并追加勘误，明确撤回继承。

完整源组、原始OCR及已登记订正、RAW完整译文、修订完整译文、实际保存mono/dual的SHA与实际文字分别呈现并绑定。审校结论指明是原MT错误、OCR源错误、结构/几何辅助、必要语义返修还是可选措辞；修过的完整组和轮次计量，不用只改几字掩盖整组辅助。只读清局部时不得为整段签PASS。无需另建通用数字检查器或发布门：沿现有具名审校，人工证据和机器未知分别保留。

按完整语义段核验八方面：完整性、条件、否定、比较、实体、数字、单位、引用。真实续段允许按完整行跨栏/跨页，完整新段保持源页起点；图注按源列结构，核定 figure/page 对应、文字完整、栏间与下方界线。逐类登记实际字号、基线、字距、对齐和留白原因，不能以填满空白或小字号容纳代替正确排版。

正文漏译、误译、重复或语义变化必须登记为待返修问题，包括单个case的问题；将完整源段、实际目标文字及PDF SHA交给获授权的执行者修复，修复后重新核验关联内容、样式及链接。低收益逐案细节优化的停止规则不能用于接受正文错误；个案正文返修不计为通用算法收益。

核对成品全部原生文字的翻译/保护归属，查原文残留与重复解释。检查链接标签实际颜色、逐行下划线和点击区、URI及内部/远程目标，所有源资产和链接都进入必要范围。扫描和图中文字另核验像素与OCR，不以空原生清单通过。

全页检查后逐个核验风险裁区，源/译页、坐标、文件SHA、实际像素、标准、审校目的与判断同时绑定。缺证据为unverified，不以预算、文件存在、旧布尔值或既有接受关闭新疑点。结果使用pass/fail/unverified/not_applicable，必要门范围不缩减；未经具体授权不晋升、发布、代修或发送消息。

以新目录保存不可变检查清单、逐项理由、疑点、实际测量和综合证据。字段本身不证明人员身份，不复制生产者的结论凑通过。


姓名混排审查：作者姓名可保留，但必须提供person_name_source_binding，并从同一源PDF已核定的author_identity/protected源行取得独立批准的姓名字符范围。person_name_review_ref须绑定同一源、标准和审校身份；不得用整行author_byline或“看起来是名字”替代姓名范围证据。贡献说明、机构和普通自然语言另译并逐字符覆盖。缺证据写unverified，伪造或明确冲突写fail。按每个接口的文本SHA规范绑定原文；完整语义门使用text_digest的NFKC SHA，姓名源证据使用原始文本SHA。保留实际文字、原始裁决、理由与不确定项。


检查实际filled和成品全页。排版库返回完成、文字能抽取或局部掩码覆盖强核心，均不足以关闭溢出、低倍率残墨及跨栏重叠。科学普通微差仅在影响阅读、含义或违反明确要求时返修；缺证事项仍为unverified。完整标签包含连接符和全部成员，实际源角色、宿主、字体及成品范围分别绑定。正式采用边界见references/formal-qa-adoption-20261009.md。


### 2026-10-09：完整脚本样式生产接入

`qa_pipeline.evaluate_quality_packet`额外要求独立源审校冻结的`script_styles_scope_ref`，实际源/目标逐页重读，所有引用成员（含连接符）重新计算并通过schema门。没有范围、少成员、身份或冻结改变保持未核验；实际样式冲突判失败。无脚本的范围须具名理由且现场源字形没有相反信号；扫描空清单不能判不适用。容差逐项冻结，仅适用于明确政策，不扩展到普通科学字形微差。组件通过仍须原有九项质量门、独立视觉和用户接受。源枚举及正文绑定改为每批1页，链接沿用全局闭合审计。


完整脚本源范围字段见 `schemas/source-script-scope.schema.json`，源/目标绑定示例见 `examples/source-script-quality-packet.example.json`。该schema用于独立审校冻结前检查字段；生产接口另按实际PDF重算，不把结构合法当作质量接受。范围从requirements_ref中的script_styles_scope_ref取得，包含source/standard/reviewer_id/source_first/pages/items；每项固定source_label_indices、source_host_anchor_index、label、source_script、逐项policy_scope_id及其容差。非空范围另绑定runtime_ref与schema_ref；目标packet的script_styles_bindings_ref须完整覆盖这些id及目标页/成员/宿主。空范围要求独立不适用理由且实际源没有脚本或扫描空清单反证。示例零SHA不可执行，不提供通用科学容差。
