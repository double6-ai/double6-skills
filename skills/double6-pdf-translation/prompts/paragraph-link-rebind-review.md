# 通用链接回写审阅

冻结源/段落字形/真实字体层的SHA和唯一策略。检查完整段落、源页/段首基线、生产字体及逐字颜色；删除后保护字形须完整。检查实际源标签全部成员唯一归属和新点击框所有成员，保存重开后非Rect字段/原动作依赖及注释数量/顺序须原样保留。检查所有未改区像素，变动区域作完整页面与局部视觉审阅。混合成员、跨行标签、字形身份改变、邻字丢失或点击框覆盖其他字形时停止，不写逐案例外。记录外部目标可用性与用户接受；不得把动作保持、局部delta核验或独立观察冒称全件strict。

原生URI的源余量由实际字形和注释推导，不手填数值。源URI集合/完整动作相同，连续同动作碎片无空隙/重叠才合并。新增框不得吞相邻字符。保存后像素应完全不变；新SHA必须通过独立重验。
