# 链接交付独立复核

先冻结当前完整源/译PDF和标准SHA，枚举全部源和译注释。检查原生字段与实际宿主，不按注释数量猜测链接增减；源一个URL变为多行多框时，完整字形及每框的动作、点击成员与覆盖须核验。不能把旧target xref或汇总P直接迁入新PDF。

远程依赖须核对同目录实际文件SHA和原生目的地、源名称树、零起点页码及XYZ。zoom0/null按规范同义处理。明确区分目标文件可解析、点击框/颜色样式接受及阅读器UI实测。

外链逐唯一地址只读检查，保留404/410、访问限制、挑战页、网络未知及mailto的不同结果。2xx部分正文可证明HTTP可达；正文等价和完整下载不得自动通过。源地址失效仍记录为源地址失效，不按链接名称逐项寻找替换地址，不签用户接受或切主。
