# 科学下标与中文内部引用写回

这两个接口属于原生 PDF 返修流程。源身份、语义角色、实际字体和完整作用域先冻结；保存后检查真实字形、非目标内容、链接和整页截图。正文漏误译必须返修，不能通过格式归一化掩盖。

## 科学下标

调用 `scripts/scientific_subscript_writer.py` 的 `plan_classes`、`apply`、`verify`。绑定源下标、源宿主、目标下标和目标宿主；类别须来自已核定的源语义/样式角色，禁止按页码、词串或单个字符创建补丁类别。相同类别统一字号比例和下移比例；不同源样式只有明确证据时才分别继承。本轮 metadata 与 body 两类分别为 0.70/0.75 倍宿主字号，下移均为 0.21 倍宿主字号，参数由源测量取两位小数，原始测量偏差不得超过 0.002。

数字和 ASCII 变量使用实际字体中的普通字形，依靠字号与文字基线绘制下标；NFKC 字符身份必须与源一致。现有普通斜体变量可保留既有源绑定，不能把 Latin y 替换成 Greek gamma。写回只支持具有唯一字形序列对应的 Identity-H 两字节 CID Form，检查实际嵌入字体与 PDF 宽度表，补偿新字形 advance，保护其后字符的位置。其它编码、缺字、重复身份、非统一源类别或未完整绑定时停止该路线。

保存后逐字检查目标字号/基线及字符身份；非目标字符、字体、颜色和位置须保持冻结容差。整页像素差异须限定在目标真实字形区域内。测量或测试通过不能代替独立视觉接受。

## 中文内部引用

调用 `scripts/internal_citation_rebind.py` 的 `plan`、`apply`、`verify`。完整枚举当前 GoToR，核对伴随文件名、源命名目标及原 XYZ 目的地，先完成全部精确语义匹配再写回。

参考文献使用编号和源命名目标前 32 个规范字符核定唯一条目；源编号独立成绘制片段时，只合并同基线、同列、距离受限且唯一的右邻片段。图引用绑定唯一源 Fig.n 图注与中文图 n 图注；公式引用绑定源目的页及中文唯一独立公式编号。未知、缺失或歧义停止完整写回，不能靠大矩形、页码或坐标例外选目标。

只修改动作 `/A` 为内部 `/GoTo`，目标使用实际中文页对象和条目/图注/公式的起点 XYZ，保留点击框及所有其它注释字段。保存后验证全部目的页对象、坐标、剩余 GoToR 数、未改注释、全文字形和内容流。阅读器中分别实点文献、图、公式，并记录实际文件和页面；抽样实点不冒充逐条实点。

绑定 schema 与例子见 `schemas/scientific-subscript-bindings.schema.json`、`examples/scientific-subscript-bindings.example.json`；复核提示为 `prompts/science-and-internal-citation-review.md`。内部绑定 schema 与例子见 `schemas/internal-citation-bindings.schema.json`、`examples/internal-citation-bindings.example.json`。两个例子中的数字只是接口形状，不能直接用于真实 PDF，必须生成并冻结实际对象身份。内部绑定从原生动作和源命名目标生成，不接受手工指定最终目的页。
