# 完整无协议头标识的覆盖守门

当前原生两页正式包首次执行发现155项unit绑定和14项保护理由字段缺失。执行者根据已独立核定的169源角色、32完整译写单位和8保护单位补齐元数据，历史失败结果保留。该修复不改变源角色、译文或PDF，也不授予独立元数据接受。

三项剩余接口失败为`doi.org/10.1002/elsa.202400004`两处与`wileyonlinelibrary.com/journal/elsa`一处。它们已具名核定为identifier，缺协议头不改变其完整URL身份。`translation_coverage._whole_identifier`沿用既有HTTP、www、邮箱和DOI规则；新增完整ASCII domain/path必须同时具有url、doi或identifier保护语境。缺保护语境、普通句段、缺路径、非法首尾连字符、普通正文角色或缺独立源角色证据仍阻断。

不修改自然语言角色或b416质量标准；不把含URL的说明句作为标识豁免。覆盖元数据、独立角色、完整译文、实际字形、语义、源样式/引用颜色、视觉和全部九门继续分别核定。原生样本源蓝色引用数字在目标中变黑的独立失败保持原身份，标识语法修复不能关闭它。2.0.0仍为未发布候选。
