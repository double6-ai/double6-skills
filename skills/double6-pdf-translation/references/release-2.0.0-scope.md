# 2.0.0 发布范围

本版发布 PR #25 合入 main 的 A+C 范围，执行逻辑基于已验收的 3f5aa5b 切片。`110-unpublished` 与 `111-20261017` 保留为历史开发路线和来源合同身份。当前软件版本见 [SKILL](../SKILL.md) 与 [机器配置](../configs/default-routes.json)。

以数字 PDF 为主，可信 LaTeX 和清晰单栏扫描按既有合同准入。完整 1–5 页走单任务；长文档使用显式分块合同，单块资源与质量门保持。扫描仍须源组、角色及全文语义审校。安装、模型、字体及 TeX 等外部依赖见 [运行依赖](runtime-dependencies.md)。

保留阅读质量门、公式层级与可读版保真检查、方向感知 QA、凭据保护、解释性失败和可核实续跑。复杂表格的结构或像素级完美、多栏及栏溢出像素级保真、脚注/引用标点几何细缝不作承诺；发现不稳定结构须拒绝或保留未验证，不能改记为通过。

发行验证绑定精确源码、ZIP 成员 SHA、独立安装和实际回放。既有样本的接受仅覆盖其精确输入和产物，不能迁移成陌生文档已获接受。每份 PDF 的技术核验、全文语义和页面审校、用户接受与严格交付分别登记；缺失证据保留未验证，质量失败候选不作为严格交付。
