# 统一URI点击留白投影

入口：`scripts/uri_padding_projection.py PLAN.json --output-dir NEW_DIR`；加 `--dry-run` 只检查和生成提案。计划见 `schemas/uri-padding-projection.schema.json` 与 `examples/uri-padding-projection.example.json`。先单页烟测，再逐页有界预检，最后生成候选并保存重开。PDF任务使用共享锁、并发1、页缓存1、树2GiB、120秒与持续资源监控；最多20页、每页1000注释、输入JSON16MiB。

源/目标按页与相同URI绑定完整原生字形中心，完整字面标签按NFKC及空白归一化后须一致；重复宿主、非文字或歧义停止本组。动作可为直接字典或一个间接字典，须为单一URI且无Next/AA/Dest。其它动作只保护，不把URI路线扩展至GoToR。

源分框的实际字形框到注释框留白各边须在3pt内，同组各框各边差≤0.5pt。用各源框均值投影到现有目标分框，保留原分行、框数与所有原生动作；实际差>0.5pt才修复。投影框须在页内且实际可打印中心成员与原框完全一致；遗漏字形或碰邻文则停止，不截断留白或调整阈值来获得通过。各组停止理由写入报告，不按页、URI或词串增加修复例外。

保存重开核对全部声明页的字形、字体、字号、颜色与位置（0.001pt）；286等具体数量从实际输入读取，不硬编码。所有注释除选中Rect外的原生字段、顺序及动作保持，未选框精确保持，改动框成员不变、投影误差≤0.001pt。通过表示这一点击几何规则实证成立，不授予下划线、图标完整宿主、外部网站、阅读器UI、整篇新SHA独立九门或用户接受。

本机真实主论文全13页验证覆盖16组/20框（重复页脚及不同分行的两类地址），另32组原已满足容差，20组按结构原因停止。源和目标均冻结实际SHA，不以测试用例中的地址冒充修复白名单。负控制及混合URI/GoToR保存实证在消费项目 `test_uri_padding_projection.py`。2.0.0继续未发布。
