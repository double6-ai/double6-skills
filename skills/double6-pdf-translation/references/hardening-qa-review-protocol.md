# QA加固审校协议

此协议用于具名独立审校；主执行者自查、模型线索和机械报告保留各自角色。不能用字段冒填外部审校者的身份，也不能由执行者代写独立决定。所有文件绑定当前SHA和适用标准。

1. **冻结范围与授权**：读取完整原始PDF，明确原物理页、目标保留规则、所有必要检查、源清单和具名审校来源。源先行复核者先建立原文角色、段落/续段边界、图注单栏/双栏/通栏、图像文字、保护对象及风险区域，再查看生产unit和译稿。记录此前暴露，普通独立复验不能冒称盲测。
2. **覆盖与保护**：范围覆盖刊头、标题、作者/机构、献词、页脚、空白带、图内文字和正文。逐源元素绑定文本SHA、页码、bbox、译文或保护上下文。DOI、URL、邮箱、公式和作者姓名只保护其身份部分；普通句子和标签继续翻译。正文误标为参考文献时依据源上下文拒绝。
3. **完整语义**：以完整逻辑段为单位核对全部源片段和译文，逐项审校完整性、条件、否定、比较、实体、数字、单位和引用。保留模型线索并说明等价表达，不因空线索返回而接受。超过4000字符先提供对齐块。
4. **写回与结构**：完整新段保持源页；真实续段允许按完整行跨栏/页。检查实际字形、连续行序、源段首、统一字号/行距/字距、声明偏移、图注栏数/起点/栏间带/分隔线净距和真实目标端点。不能用相同pt、页数或CSS声明证明成品可读。
5. **视觉与留白**：整册逐页检查并复核全部必检区域，图注和跨栏续段必须含完整两侧源片段及目标片段。裁图按PDF SHA、页码、bbox、DPI和实际像素重绘验证。每个异常留白区记录源空白、译文变短、原页锚点限制或真实结构缺陷及证据。视觉上下文预算耗尽时保留unverified；先缩小疑点再追加最小裁图，不能据此创建新的用户任务。
6. **资产与链接**：逐项核对图像保护、公式内英文、科学标识、引用、颜色、上下标、逐行下划线及点击框。URI正确不足以证明显示标签和点击区域正确；点击框不能吞并相邻普通文字。正文最终引用、实际图片、索引和生成脚本一起核对。
7. **四态汇总**：源清单、角色、覆盖、段落、图注、间距、语义、视觉、资产/链接九类检查均有明确范围、已查项、未决项和证据。pass/fail/unverified/not_applicable分别保留，不适用需要源证据。正式综合包提供content_inputs和visual_inputs；正面汇总不得替代真实字形或裁图。任一失败或待验证均阻止晋升。
8. **返修与接受**：局部返修后复查关联段落、整页、风险区域及上下游依赖；当前SHA和标准改变时重新绑定。quality pass、用户本人接受、strict、promotion和Skill发布分别登记。缺具名批准时保留候选，并继续可独立完成的诊断和修复。

大任务串行小批次：默认每批最多5页、并发1、任务4GiB、16进程、watchdog5秒。记录任务及Codex内存；Codex超过20GiB或系统内存压力立即熔断。

成品闭合时先保存全部保护源行的`protected_bindings_ref`，核验完整行文字与实际字形；所有未归属原生字形必须逐项解释。译文登记完整但原文残留同样拒绝。扫描/OCR/图中文字不能由原生字形计数关闭。

链接审校另冻结`native_links_ref`：当前源/译/标准及具名审校人，method为source_first，全册源/译页清单和target_page_map；regions逐项给源/译标签框、基色、标签、源继承色/下划线参数/padding及URI。检查全册实际注释，未登记URI和内部目标保持未知；中文标签可跨印刷行，但每行装饰与点击框按实际字形生成。颜色和源参数差异须回到源证据修订合同，不能让译文另定规格以通过。
