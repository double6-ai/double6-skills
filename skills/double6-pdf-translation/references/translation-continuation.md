# 默认续译策略

默认策略：小问题不拒绝整篇；正式稿不加入虚构的方括号补词、审校说明或页脚提醒。`translate` 是普通入口，`candidate`、`chunked-candidate`及交付验收入口保留原严格语义。

## 执行与产物

`paper_translation_workflow.py translate --input <PDF> --output <新目录> --target-language zh|en` 自动逐页识别原生/扫描类型，生成源范围、模型和代码SHA冻结，调用既有单页candidate。长文档不再因普通单份5页上限而要求用户重新准备；模型与端点始终采用明确配置，不静默换模型。默认不发现/下载论文LaTeX再要求用户验证它。

每次页任务仍是有界子进程，内部OCR与后端共享该页资源合同。完成即记入`TRANSLATION_STATE.json`；前一页失败后，必须确认其进程已回收再开始下一页。`--resume`核对原件、代码、配置与已完成页SHA，仅重跑失败或被改动的页。环境/代码变化时自动开新运行目录，不混用旧冻结；原件在运行中被替换则立即停止。

正式PDF无过程说明。审校记录只放在`翻译审校记录.md`和`翻译报告.json`。可用输出保持原页顺序；局部保留、整页保留有精确页号和OCR区域证据。没有任何可用译文时输出`原文保留稿.pdf`、状态`blocked/no_pages_translated`，不把它称为翻译成功。

## 决策表

| 发现 | 默认处理 | 会不会停止整篇 |
|---|---|---|
| 个别低置信字/行、损坏编号 | 实际OCR复核；仍不可靠则保留该完整段落原图，其余段落继续 | 不会 |
| 低分辨率但仍能识别可靠正文 | 警告并尝试OCR；可信段翻译，不可靠段保留 | 不会仅因dpi不足停止 |
| 可定位数学行、上下标 | 保留相应源段落的原图，不改写公式 | 不会 |
| 扫描表格中的局部印章、签名、低置信或译文溢出 | 定位单元格，可靠字段继续翻译；受影响单元格原图保留 | 不会 |
| 复杂底图与文字相交 | 完整资产及相交完整段落保留，其余段落继续 | 不会 |
| 无法定位安全区域的表格、公式/分式、复杂混排 | 当前页原样保留，继续后页 | 不会 |
| 新译文字压住保留原图区域、严重叠字/字形损坏 | 拒用该页坏候选，保留原页 | 不会拖住后页 |
| 局部样式、链接、附加可读版、审校证据欠缺 | 输出可用版并另列事项；不授予相应质量接受 | 不会 |
| 服务临时限流/5xx | 在原页预算内最多3次请求、8/16秒退避；已有可靠首译不因可选压缩重试失败被丢弃 | 不会直接当作额度耗尽；真实鉴权/额度错误仍停止 |
| 模型JSON或占位符等异常 | 沿既有有界重试；无可用页后保留原页，支持恢复 | 不会仅因一页失败停止 |
| 单页超时、任务内存超限 | 回收所属任务、保留该页、继续后页 | 确认回收后不会 |
| 模型库存404/空列表/未列出指定别名 | 记录诊断警告，实际请求仍用指定模型 | 不会 |
| 原生页已在目标语言、空白页 | 原样通过，不调用模型 | 不会 |
| 多页、既有输出目录、缺手工FREEZE/人工验收材料 | 自动拆页、自动冻结或新建运行目录 | 不会 |
| 无效凭据/权限、不可用额度、实际模型不存在 | 停止新调度，保留进度，修好后恢复 | 会 |
| 文件损坏/需密码/不能读取、输出不能写 | 明确原因，不能伪造译文 | 会 |
| 处理中原件变更、进程归属/回收不能确认、系统级内存压力 | 停止，保护输入一致性与机器资源 | 会 |
| 整篇最终没有任何可用译文 | 保存原稿和问题清单，明确未译成 | 会以未译成结束 |

`completed_with_warnings`允许有用结果先输出；`partially_translated`说明某些原文区域仍保留，`original_preserved`说明该页没有被翻译。页级范围处理完成不等于语义质量或用户接受。`quality_status=unverified`以及`strict_delivery=false`不会阻断普通续译。

## 局部OCR保留的边界

续译冻结显式带`continuation_policy=local_preserve_v1`，扫描页带`ocr_failure_policy=preserve_regions`，并实际传`--ocr-preserve-local`。原有严格OCR默认不变，不能把宽容模式材料冒充严格准入。

不确定行、数学行及图像几何上下标所在的整个OCR段落保留为背景图；其余可靠文字写回后交给已有PDF后端。背景残留检查仅豁免SHA绑定的已保留区域，区域外残留仍使该页退回原件。候选译文的文字框若覆盖保留区域，拒用该坏页。无法定位的分式等仍按页保留。

网格表页由 `ocr_region_translation.py` 定位封闭单元格，去线副本做稀疏文字OCR；原图不去线。仅可靠单元格调用真实模型，缺失/重复/损坏的模型单元局部保留。灰底和竖排字段增加单元格OCR交叉复核。表格按行高选择全页共同7.5–9pt字号、1.3倍基线；表外标题12pt/15.5pt、说明11.5pt/15.5pt。实测溢出先在剩余预算内用真实模型压缩重试一次，仍放不下时保留该区域，不逐格缩字。保留原PDF图像对象，只覆盖可信文字框；保存后检查实际字形、区域边界、全页红色墨迹及允许范围外像素。单元格源文、保留原因、模型回执和 `REGION_RENDER_AUDIT.json` 留在附件。单元格检测和OCR可能漏字段，技术核验不证明覆盖完整或语义正确。

内部OCR重建源必须同时核对冻结输入、OCR清单、重建源与逐行明细SHA，才可越过重复的原生电子页分类；不放宽外来隐藏文字层的准入。普通中文夹大写编号/路线代码不能仅凭 `isupper()` 判断为标题。

中文水平单栏公文、通知默认先做源文字复核和语义顺排；执行者的源文修正通过 `--source-review` 输入，程序自动生成输出布局。普通入口默认允许覆盖印章，指定 `--stamp-policy preserve` 时保护完整印章与相交段落。详见[扫描版式处理](scan-layout.md)。

后端译文与原图保留区发生冲突时，先核实前一进程树已回收，再在该页剩余预算内尝试源段落分区重译。此时用真实模型重新翻译可靠段落，统一正文11.5pt/15.5pt基线；放不下、互相穿插或与保留资产相交的完整段落原样保留，其余仍输出。旋转坐标未核定、剩余预算不足或没有任何安全单元时才保留原页。此分支不提高单页资源上限。

不会把不确定文字猜成正确原文，不会因继续生成而宣布OCR正确，不会在正式页塞“本段未翻译”等标签。读者要知道哪些地方仍是原文时查看独立审校记录。

## 仍有的实际限制

本入口优先保障继续工作与原内容保全；单页后端无法安全排版、复杂结构或不可靠识别仍可能使该页保留原文。跨页术语、段落衔接、细密公式/图表的语义与版式仍需相应审校。资源、模型服务、底层PDF读写引擎真正不可用时无法靠继续策略生成译文。可选诊断工具缺失不应被当成整篇生成失败。

严格验收仍可发现并限制质量声明，且必须保留未解决的问题；它与“先输出能用的译文”是两个阶段。用户对某份结果的明确接受记录其真实范围，不自动扩展为新流程或整个skill已发布。
