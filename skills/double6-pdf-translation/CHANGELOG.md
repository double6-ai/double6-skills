# double6-pdf-translation 变更记录

## 1.0.4

- 本地兼容代理不再转发调用方的 `Authorization` 头，只使用本次显式配置的上游 key。

## 1.0.3

- 凭据、endpoint、模型和 provider 改为仅接受本次命令显式参数，不再扫描宿主环境中的 key。
- LaTeX 源码与本地兼容代理改为仅显式启用，移除相邻目录自动发现和运行时动态导入外部代码。
- 默认运行缓存收进输出目录，并移除可由环境变量重定向的项目、运行和共享目录。

## 1.0.2

- 删除会按特定文档硬编码改写文本或克隆原文区域的后处理。
- 子进程改用环境变量白名单，避免继承无关凭据。
- endpoint 预检改为显式联网授权，并移除关闭宿主安全策略的安装绕过。
- 在入口描述中完整披露本地读取、远端传输、子进程与输出副作用。

## 1.0.1

- arXiv 源码下载改为显式 opt-in，默认不访问 arXiv。
- Docker LaTeX 编译改为显式 opt-in，默认只检查本机编译器。
- 明确模型 endpoint 授权、输入文件只读、输出目录派生写入和外部代码路径信任边界。

## 1.0.0

- 首次面向 skills.sh 与 ClawHub 发布。
- 支持将非扫描版英文 PDF 翻译为简体中文，并生成中文单语与中英双语 PDF。
- 要求用户显式配置模型、API endpoint 和 credential，不携带默认模型或密钥。
- 增加 ClawHub 版本、主页、运行时与环境变量元数据。
