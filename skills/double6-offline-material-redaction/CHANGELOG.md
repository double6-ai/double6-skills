# 变更记录

## 未发布 — 脱敏复检修正

基于 0.7.0，版本号未改。

- 一条批注里只要有一个字被盖住，整条就拒绝。每个字形单独看去掉批注后的文字边缘还在不在、明暗差还够不够，不再把整块矩形里的可读正文平均进去。字形小到对不齐，同样拒绝。任一渲染器对这个字判盖住或判不了，就拒绝。因此大方块里只在数字上画互不连通小黑块的外观会停止，包括只盖住一位数字。压在号码上的审批图章如果把其中几个数字的边缘压糊，也会停止；空白处的图章仍可去掉。透明度 0.25 的黑方块整块看仍可读，但有一个数字两种渲染看不一致，同样停止。
- UserUnit 的交叉引用类型除 real 和 int 外，也接受 float。PyMuPDF 会把 1.25、1.5、2.5 报成 float。大于 1 的非整数同样在涂黑前暂时写成 1，涂完再写回。小于 1 仍然不改，仍拒绝。
- 浅色 0.985 的字低于 0.99 的不可见文字门槛，在既有规则上就会交付，不是这次逐字形判断新开的口子。批注矩形外长边不到 12 个预览像素的差分跳过，没有单独把已经藏住的号码交出去。
- 批注矩形以外、长边不到 12 个预览像素的画面差分，不当成遮盖。Windows 上普通黄色高亮会让页面另一处的字边重画大约 4×9 像素，这块小窗会被误判成把字盖住。能盖住号码的框外外观比这长得多，仍然拒绝。
- 批注改为看有没有把底下的字盖住，不再因为删除前后像素变了就拒绝。每条被删批注用 pdfium 和 MuPDF 各渲染有批注、无批注两张图，只统计去掉批注之后还在的文字边缘。任一渲染器判盖住、看不清或对不齐，或者两边结论相反，就停止。文字层有字但画面没有这些边缘，停止。批注下有没框选的矢量或图片，停止。类型名、颜色和线宽都不是放行条件。因此普通高亮、下划线、删除线、波浪线、可见便签、不盖住字的图章和空白色块可以去掉；用户自己画的不透明黑框、灰底白边、把字涂平或涂糊的色块仍然停止。线宽为 0 但盖住字的方块，报错说明是把字盖住了，不再说画面变了。空白上的线宽 0 方块可以去掉。不可见或半透明文字、文字或图片被后绘制对象遮住，仍按原规则停止。设了隐藏标志、两个渲染器都没有画出来的方块，字本来就看得见，可以去掉。
- UserUnit 大于 1 时，涂黑前暂时把该页 UserUnit 写成 1，涂完再写回。PyMuPDF 会把已经按 UserUnit 放大过的宽高再乘一次，黑块超出选区，复检就误说切到了框外，或在没有批注时仍提示先去掉批注。选区本身不缩小，缩小会留下正文。小于 1 的 UserUnit 不做这个改写：同一写法会把黑块缩小，尚未证明不会留下字形，所以仍拒绝。大于 1 且页面上还有不透明黑框时，仍然因为黑框盖住字而拒绝，这不是原来的框外误拒。
- 带普通文字批注的 PDF 仍走默认文字路线。复检用“只去掉批注和链接”的页面做像素基准，不盖住正文的图标消失可以交付；框外正文被切到仍然停止。不透明白框若盖住正文，去掉之后框外多出的深色像素会停止交付。
- CSV/TSV 只给真正的公式文本加单引号，普通负数保持原样。公式字符前的不换行空格、全角空格、行分隔符、换页和垂直制表符同样加引号。保留项必须来自原文单元格；引号、多出的空格或新写入的替换标记不算保留。
- 网页把跨行选区记成一项。短数字若会改掉前后连着的业务编号（换行、空格或不可见字符隔开也算）会停止，错误里不回显那段原文。
- 补选词若会重新出现在`【已隐去N】`里，改用`〔已处理A〕`。正文里已经有同一套标记时也视为冲突；两套都不安全时停止。
- 建议词覆盖空格、连字符、全角和零宽电话，以及全角邮箱、校验通过的身份证和银行卡，仍不自动套用。紧挨订单号的 11 位数字不再当成电话。
- 已撤回两处会漏脱的放行：不能因为正文里有替换标记就把对不上的补选词原样交付；补选数字只要还出现在输出里（包括更长数字中的一段，或夹了不可见字符）就停止，不再切短后声称已经不在。
- 盖住正文的方块、圆形、自由文本或印章批注，不论比底下的字更深还是更浅，只要删掉后框外还有这段字形，就停止。空白处的黑块、高亮、下划线和便签图标仍可交付。只变深的像素比较继续保留。
- 短数字右侧紧贴汉字或字母，或任一侧隔着连字符，都按前后连着的业务编号停止，错误里不回显该编号。
- 同一串数字若还以空格、连字符、不换行空格、全角空格、点号，或阿拉伯-印度数字、数学粗体、上标留在正文里，停止交付，不在错误里写出该号码。不改成“交付成功但提示还留着”，因为成功副本里仍能读到这个号码。
- PDF 保留项在原文或副本里对不上、且没有其它复检失败时，错误说明是保留项没有对上。框外字形或隐藏对象仍用原来的框外说明。
- 批注是否揭开内容，改为比较带批注的渲染和去掉批注后的渲染。框外出现原来看不见的文字、矢量或图片，或者批注自身带有可见内容，都停止。便签、链接、高亮、下划线和删除线仍可去掉。纯色块盖在纯色空白上仍可交付。直线、折线盖住号码，以及黑方块盖住矢量笔画，都会拒绝。报错提示先去掉方块或批注，或把被盖住的内容一起框上。只有描边、或很低透明度但仍盖住可读内容的方块，也会拒绝。
- 同一串数字不论先选哪种写法都拒绝。归一化使用 NFKC、全部十进制数字，以及数字之间的空白、格式字符和常见分隔标点；换行和制表符仍分开。短编号两侧的下划线、斜杠，以及数字-连字符-数字，都算连在一起。七位及以下数字若隔着空格或换行碰到汉字，整单拒绝，报错提示把整段一起选上。
- 批注复检按渲染取样到矩形外沿，不再向内缩。去盖后只要比盖着时多出任何深浅差别，或文字、矢量、图片落在矩形里，就停止。浅色字、贴着边的细字、旋转页、裁剪框偏移和 UserUnit 用同一套页面到像素的变换。旋转的平移按 UserUnit 放大，和文字坐标、显示矩形一致；批注矩形先回到这套坐标再比较。页面框不从原点开始时也用这套显示矩形。裁剪框和旋转同时出现仍拒绝。图章、墨迹、附件图标和描边本身有可见内容时，报错改说批注本身有可见内容，并提示先去掉这块批注。变体选择符以及数字之间的非间距、包围和格式字符都算同一种号码。
- 高亮、下划线、删除线、波浪线、便签、弹出框和链接不再按类型整段跳过，和其它被删批注走同一套去盖前后比较。普通半透明高亮、下划线和便签底下的字本来看得见，仍可交付。这些名字如果带不透明黑外观，预览里看不见的号码会停止，不交付。链接和弹出框也看实际渲染，不看类型名。PyMuPDF 枚举不到的 `/Annots` 同样去掉并参与比较。图章，以及线宽为 0 的黑方块，整块落在选区里且矩形内没有未选中的对象时可以交付；只框旁边的字仍然停止。
- 撤回按类型、颜色或线宽放行。每条被删批注比较删除前后的渲染，外接矩形含边框、相交的外观框，再外扩 2 个预览像素；里面有任何像素变化就拒绝，不设颜色或亮度门槛。同一渲染器下没被批注碰到的正文前后像素相同，所以不把抗锯齿噪声当成容差，这 2 像素只把描边边缘收进比较范围。矩形里还有没框选的文字、矢量或图片也拒绝。灰底白边、渐变、双色、纹理、半透明和只描边都拒绝。因此这些以前能交付的情况现在会停止：普通高亮、下划线、删除线、波浪线，可见便签，空白上的色块，把被盖住的号码或整页框进选区，整块框住的图章，线宽为 0 的黑方块，以及矩形盖住未选文字的链接或弹出框。页眉色块、表格底色，以及不改像素、也不压住未选对象的隐藏批注，仍可交付。裁剪框和旋转同时出现仍拒绝。UserUnit 下把盖住的号码框进选区后的误拒保持原样，本轮不改。

## 0.7.0 — 原格式与首次使用改进

- Python最低兼容目标下调至3.10，覆盖3.10–3.14；解释器版本和架构绑定安装回执。
- 默认新建同格式副本；保持PNG/JPEG/WebP、.markdown、XLSM及ODF容器类型，转换须明确选择；旧格式不能安全原格式导出时停止。
- PDF默认原生删除选定内容、保留框外可搜索文字和页面；复杂隐藏内容明确拒绝，图像化仅作显式选项。新增AGPL-3.0 PyMuPDF外部依赖并标注许可。
- 安装自动执行正反例验收，成功后生成双击入口、本机离线说明和个性化命令。报告与入口均写新目录。
- CLI与HTML共用格式策略；网页结果使用中性时间戳加随机标识，不带出原文件名；开始新框选即撤销旧下载与确认，整字对齐失败也不恢复旧结果。
- 补齐27正例、28反例和85项源码回归；支持可证明完整可见的矩形裁剪和嵌套Form，保留对真实隐藏原文、裁剪图片、遮罩、遮挡与页面外载体的阻断；原生副本按同一原件及计划做确定性重建比对，拒绝外部黑盖伪装。

- 清理PDF对象级元数据与私有历史，拒绝未知私有绘制字段和图片替代载体，新增安装正反例。
- PDF整字对齐在网页先显示实际黑块，CLI需明确选择；表格底色、可证实的深色背景白字与正常Office分页纳入原生处理。
