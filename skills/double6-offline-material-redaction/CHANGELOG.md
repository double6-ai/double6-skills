# 变更记录

## 0.7.2 — 真实办公样例回归与优化（2026-11-02）

来自真实办公样例端到端实测的三处修复与一组性能优化。测试 168 项源码回归全部保留并新增回归文件。

- Excel 兼容 LibreOffice/Excel 的常见货币写法：`\¥#,##0.00`（反斜杠转义字面符号）与 `[$¥-804]#,##0.00`/`[$US$-409]#,##0.00`（区域货币前缀）。显示读法仍是"符号+数字"；带负数分节、条件或未知符号的格式仍按原样停止。
- PDF 默认保留批注路径：框选被高亮/下划线等批注盖住的正文不再误拒。此前 `get_drawings()` 把批注外观算进页面矢量，部分覆盖即报"框选只覆盖部分复杂矢量内容"；现矢量检查只看页面内容，批注整体保留，不存在部分矢量可恢复的问题。「一并清除批注」路径行为不变。
- 图片计划中非空 `keep` 保留项现在显式拒绝（图片副本没有可搜索文字，此前会被静默忽略），避免保留项"已检查"的假确认。
- 性能：新增 `engine.TermScanner` 与 `engine.strings_absent`，整段文本的折叠与数字切分只算一次，供逐词复检复用（40 万字符×200 词的批量复检从约 4 秒降到约 0.15 秒）；`rewrite` 增加首字符预过滤（同场景约 1.1 秒降到约 0.16 秒）；`formats.pdf_image` 支持复用已算好的页面尺寸，PDF 复检不再每页渲染前重复整册校验；Excel 模型仅在存在公式时才二次解析缓存值工作簿。
- 清理：ODF 构造中未使用的中间对象移除；导出对象与判定语义均不变。
- 基础验收新增 1 个正例（默认保留盖住框选词的高亮），现为 29 个正例、32 个反例。

## 0.7.1 — 正式源码发布（2026-10-25）

基于已合入的 PR #28、#30，明确 0.7 产品边界，并将源码、安装回执与运行时版本统一为 0.7.1。

- PDF 默认删除用户框选的正文并保留批注。能确认批注文字含本次要隐去的内容时，按安全条件只删该条；删后会露出未框选的文字、线条、图片，或批注读不全时，整份停止。错误不回显原文。
- 「一并清除批注」默认关闭，须通过 CLI、计划或网页明确打开。打开后沿用严格像素规则：批注外接范围内任何像素变化、或仍有未选对象，都停止；不按类型、颜色或线宽放行。图像化不能代替清批注，不自动烧入批注。
- 加强可读取的批注文字、外观字符串及支持的常见载体核对。数字的分隔符、全角、变体选择符和其它受支持数字写法均参与复检；补选词仍残留时停止。
- CSV/TSV 保留普通负数，仅中和公式样式文本；声明保留项按原单元格核对。修正替换标记冲突、跨行选区和短业务编号误改问题；建议词仍需本人补选确认。
- 基础验收为 28 个合成正例、32 个反例；源码回归 168 项。安装、命令和网页说明同步更新。
- 源码 Skill 分发，不含 Python、Office、第三方 wheel 或模型。原创源码 MIT；外部 PyMuPDF/MuPDF 依赖适用 AGPL-3.0，见运行依赖声明。

支持范围：正常办公材料的已选内容与当前支持载体；不承诺自动找全未补选内容、穷尽恶意 PDF 对象图或密码学擦除。UserUnit 页面误拒、裁剪框与旋转并存等已知限制保留，详见格式和验证范围说明。历史开发轮次的放行策略以 Git 历史为准，本版当前策略以上述规则为准。

## 0.7.0 — 原格式与首次使用改进

- Python最低兼容目标下调至3.10，覆盖3.10–3.14；解释器版本和架构绑定安装回执。
- 默认新建同格式副本；保持PNG/JPEG/WebP、.markdown、XLSM及ODF容器类型，转换须明确选择；旧格式不能安全原格式导出时停止。
- PDF默认原生删除选定内容、保留框外可搜索文字和页面；复杂隐藏内容明确拒绝，图像化仅作显式选项。新增AGPL-3.0 PyMuPDF外部依赖并标注许可。
- 安装自动执行正反例验收，成功后生成双击入口、本机离线说明和个性化命令。报告与入口均写新目录。
- CLI与HTML共用格式策略；网页结果使用中性时间戳加随机标识，不带出原文件名；开始新框选即撤销旧下载与确认，整字对齐失败也不恢复旧结果。
- 补齐27正例、28反例和85项源码回归；支持可证明完整可见的矩形裁剪和嵌套Form，保留对真实隐藏原文、裁剪图片、遮罩、遮挡与页面外载体的阻断；原生副本按同一原件及计划做确定性重建比对，拒绝外部黑盖伪装。

- 清理PDF对象级元数据与私有历史，拒绝未知私有绘制字段和图片替代载体，新增安装正反例。
- PDF整字对齐在网页先显示实际黑块，CLI需明确选择；表格底色、可证实的深色背景白字与正常Office分页纳入原生处理。
