# 原格式默认值与处理边界

0.7.1默认新建同格式副本。不能安全保持原格式时停止；不得只换扩展名，也不得根据输入自动选择转换。CLI的`--output-format`/计划字段、网页的输出格式选择才表达显式转换。PDF图像化是独立的显式选择。

| 输入 | 默认结果 | 处理与限制 |
| --- | --- | --- |
| PNG | 新PNG | 白底消除透明像素中的原内容；清元数据，框外像素一致 |
| JPG/JPEG | 新JPG/JPEG | 原扩展名和JPEG编码保留，质量100无色度抽样重编码；框内黑色最大误差8，框外每通道最大误差8、RMS不超过1.5；失败停止，不能声明像素完全一致 |
| WebP | 新WebP | 无损重新编码，单帧、清元数据，框外像素一致 |
| PDF | 新PDF，原生删改 | 默认只删除框选正文，批注和链接留下来；框外文字可搜索，位置和页面仍核对；清文档级属性和附件。批注文字里若能确认有这次要隐去的内容，并且这块批注没有盖住还没框选的文字、线条或图片，就只删这一条（图标可以消失）。读不全批注文字，或删掉会把没框选的内容露出来，整份停止，错误里不写出原文。只有计划或命令明确打开「一并清除批注」才去掉全部批注和链接。打开之后，去掉批注后的页面用来判断涂黑有没有切到框外字形，批注图标消失本身不算这项框外破坏。每一条被删批注再单独比较删除前后的渲染：外接矩形含边框、与矩形相交的外观框，并外扩 2 个预览像素，范围内任何像素变化都停止，不设颜色或亮度门槛。矩形里若还有没框选的文字、矢量或图片，同样停止。类型名、颜色和线宽都不能放行。浅色字、贴边细字、旋转、裁剪框偏移和 UserUnit 都按同一套预览坐标比较。在这条清除路径上，普通高亮、下划线、删除线、波浪线、可见便签、空白上的色块，以及整块框住的图章或线宽为 0 的色块，都会停止。盖住未选文字的链接或弹出框，即使像素没变也停止。不改像素、也不压住未选对象的隐藏批注可以去掉。不会自动把批注烧进页面，也不用变暗程度或细条宽窄判断遮没遮住。页眉色块和表格底色是页面内容，不是批注，仍可交付。报错说明页码和是哪一块，并请先去掉这块批注，尤其是盖住正文的那一类。保留项对不上时单独说明，不写成框外失败。加密、修复、可选图层、表单/签名域、不可见/半透明/极小文字、无法证实可见的白色文字，以及文字被后绘制对象遮住时停止，不自动图像化 |
| DOCX | 新DOCX | 重建支持的可见文字与表格，页眉页脚移到正文；不复制批注部件，修订、隐藏内容及原属性也不带入，图片与版式不保留；需接受损耗，复杂对象拒绝。这里不复制批注，是因为整份按可见文字重建，和 PDF 默认保留批注不是同一条规则 |
| TXT、MD、.markdown | 保留扩展名的新文件 | 按完整源码替换，保留已识别/明确指定的源编码、BOM与行尾；前置信息、注释和链接都须人工补选，不自动猜测编码。网页把跨行选区当作一项，不用换行拆成短词；短数字若会改掉前后连着的业务编号（左右两侧都算；空格、换行、连字符、下划线、斜杠，以及数字和数字之间的连字符都算）会停止，并提示把整段一起选上。建议可识别空格、连字符、全角和零宽电话，以及全角邮箱、校验正确的身份证和银行卡，但不会自动套用；紧挨“订单号/订单/单号”的 11 位数字不当成电话。补选词只要还留在输出里就停止。同一串数字不论选中的是哪一种写法，空格、连字符、点号、斜杠、下划线、其它空白、变体选择符、其它不可见字符或十进制数字字形留下，都不交付。正文里的替换标记不能证明已经处理过 |
| CSV/TSV | 新CSV/TSV | 保留分隔类型、行列和文字值，保留已识别/明确指定的源编码与分隔行尾。普通负数不加引号。等号、加号、减号、@ 前面即使有不换行空格、全角空格、行分隔符、换页或垂直制表符，仍加单引号。保留项必须在原文里就有，并按原单元格留下；引号、多出来的空格，或新写入的替换标记，都不算保留 |
| XLSX | 新XLSX | 重建支持的可见值和数字显示；隐藏表行列、公式、宏、图片、图表、链接、批注和原属性不带入。缓存缺失或条件/同色/未知显示规则停止。不带入批注是因为按可见值重建，和 PDF 默认保留批注不是同一条规则 |
| XLSM | 新XLSM | 保留宏启用容器类型，宏内容移除；其余同XLSX，不因原件含宏自动输出XLSX |
| PPTX | 新PPTX | 重建可见文字和可编辑表格；备注、批注、隐藏页、图片/图表、母版/动画和原属性不复制，分页重排，需接受损耗。不复制批注是因为按可见文字重建，和 PDF 默认保留批注不是同一条规则 |
| ODT/ODS/ODP | 新ODT/ODS/ODP | 直接读取支持的可见内容，重建最小ODF同格式容器；不需Office，保留文字/值/表格，原布局和复杂对象不保留 |
| DOC/RTF/XLS/PPT | 停止 | 原容器暂不能安全导出。只有明确选DOCX/XLSX/PDF等受支持路线才转换，另需LibreOffice；PPT转PDF也不默认图像化 |

PDF预览仍使用144dpi像素坐标，逐页核对和框选。原生复检检查框内文字已删除、框外文字位置、框外页面像素（只容许边缘两像素抗锯齿差异）、声明的保留文字和支持的隐藏载体。默认不清除批注：框外像素直接和原页面比；若某条批注因为写着要隐去的内容而被删掉，基准改为只去掉这几条、尚未涂黑的页面，图标消失不算框外破坏。批注文字能完整读出且不含要隐去的内容就保留。能完整读出且含有这些内容，但外接矩形里还有没框选的文字、矢量或图片，或者这块范围本身无法确认，整份停止，不交付会把内容露出来的副本。附件、声音、影片、屏幕、富媒体、三维、带嵌入文件、外观里的图片、解析不了的富文本，以及读不出的外观流，都按读不全整份停止。错误只说明页码和是哪一类，不回显原文。只有明确打开「一并清除批注」时，才去掉全部批注和链接，并用去掉这些对象、尚未涂黑的页面判断涂黑有没有切到框外。每一条被删批注再比较删除前后的整页渲染。外接矩形含边框和与它相交的外观框，再外扩 2 个预览像素，只为把描边边缘收进来，不是忽略差异的容差。范围内只要有一个像素不同就停止，变浅、变深或换色都算，不设颜色或亮度门槛。矩形里还有没框选的文字、矢量或图片也停止。同一渲染器、同一比例下，没被批注碰到的正文前后像素相同，所以不另加抗锯齿容差。类型名、颜色和线宽都不能放行。旋转平移按 UserUnit 放大后再用；裁剪框和页面框的偏移已经含在显示矩形里。裁剪框和旋转同时出现时仍拒绝。在这条清除路径上，普通高亮、下划线、删除线、波浪线、可见便签、空白上的色块，以及整块框住的图章或线宽为 0 的色块，都会停止。盖住未选文字的链接或弹出框，即使像素没变也停止。不改像素、也不压住未选对象的隐藏批注可以去掉。不会自动把批注烧进页面，也不用局部对比、变暗程度或细条宽度决定删还是留。页眉色块和表格底色不是批注，仍可交付。相对相应基准，框外正文被切坏或其它像素变化仍然失败。保留项对不上且没有其它失败时，错误写明是保留项没有对上。清除路径上批注被拒绝时，说明页码和是哪一块，并请先去掉这块批注。网页在框选完成时对齐完整字符，并显示实际黑块，用户核对后才导出；不因对齐而把框外变化算成通过。网页上的「一并清除批注」默认不勾选。CLI可明确选择整字对齐，范围写入effective_pages；清除批注用`--clear-annotations`或计划字段`clear_annotations`。影响框外内容或删除了声明保留项时仍停止。扫描件本来没有文字层时不新增OCR。Word、Excel、PPT 仍不把批注部件复制进重建副本，这和 PDF 默认保留批注不是同一条规则。

只有选择`pdf_mode=rasterize`并接受损耗，才重建144dpi纯图像PDF；原文字层、签名和交互不保留。最多20页、总4000万像素，文件输入/输出20MB上限。此模式不能使用文字keep冒充验证，也不能和「一并清除批注」一起用。图像化不是清除批注的办法，工具不会为了清批注自动把批注烧进页面。

## 产品路径与不承诺

0.7 对 PDF 承诺的是正常办公材料上的这条路径。默认只删除用户补选的正文，批注留下来。批注文字能确认含有这次要隐去的内容时，只删这一条；删掉会露出还没框选的文字、线条或图片，或者这段文字读不全，整份停止，错误不回显原文。正常办公样例走默认路径时，补选正文会删掉，漏脱为 0，批注里能够确认的命中也按同一条规则处理。「一并清除批注」必须单独打开，默认关闭；打开后按已经合入的严格像素规则，外接矩形里任何一个像素变化都拒绝，没有颜色或亮度门槛。

不承诺穷尽 PDF 对象图里的对抗式隐藏。假 BOM 再插入空字节、冷门字典键、没用到的字体 ToUnicode 映射、间接流里藏的字，都只是见过的例子，不是完整清单。已经做过的常见载体核对是尽力范围。这个技能面向正常办公材料，不面向故意构造的恶意 PDF，也不承诺密码学意义上的彻底擦除。以后新挖出的对抗样例记入待办，不作为这一版合入的否决项。

图片转换为另一编码、.markdown转.md、XLSM转XLSX及ODF/旧格式转现代格式只在明确选择时执行。同格式保留不等于任意版式或计算能力无损；必要业务依赖图片、复杂样式或公式时应停止。

文本默认UTF-8或带BOM的UTF-16，GB18030需明确选择。Excel显示支持General、文本、固定零编号、常规小数/千分位、百分比、常见金额及文档既有受限日期格式；复杂条件显示、同色字、主题/索引颜色无法解释时不猜测。ODF/旧表格格式化值可能转为显示文本，保留业务读法不代表保留原计算类型。

PDF同时使用裁剪框和旋转时，原生坐标暂未纳入支持，工具明确拒绝；单独裁剪或旋转已有合成验证。不会自动改为图像化副本。

原生PDF支持直接文字/可见图片、实际内容完整落在裁剪区内的轴对齐矩形裁剪，以及经过同样可见性检查的嵌套FormXObject。办公软件常用的分页/页眉矩形裁剪不再一律拒绝。白字只在能证实它位于不透明深色矩形底色上时接受；纯色表格背景保留，框选只覆盖部分复杂矢量或描边时停止。矩形背景仅容许0.05pt的办公导出边缘舍入，文字和图片没有这一容差。

含实际被裁掉的原文字/图片、非矩形裁剪、文字裁剪、行内图片、透明/软遮罩、渐变、图案、替代文字载体、超出页面或被后来对象遮住的图片仍停止。例如PPT形状阴影可导出为带遮罩图片，不能因它来自办公软件就跳过检查。密排行距导致删改波及相邻行也会被框外复检拦截；可在源软件调整版面后另存一份PDF再试，或明确选择图像化副本，工具不替用户切换。输出递归检查Form和图片资源，不保留未调用的旧资源；清理各对象的Metadata、PieceInfo和修改历史，未知私有绘制字段、嵌套混合组/资源私有字段与图片替代载体停止。


原生PDF的独立verify仅接受与同一原件和计划按本工具确定性重建完全一致的副本，再核对文字、页面与资源；单独给原图盖黑或加入额外载体不能算通过。后来绘制的描边、文字等与原图相交也按遮挡停止。

文字字形超出可见页面或裁剪边界时，也按隐藏原文停止；不能只检查页面上能看到的文字。
