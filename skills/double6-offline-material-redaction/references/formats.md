# 格式选择与输出变化

当前版本0.6.1。输入和输出均受20MB限制；新格式支持不表示任意复杂对象无损编辑。

| 输入 | 实际处理与输出 | 必须核对 |
| --- | --- | --- |
| TXT | 全文所选词替换，输出UTF-8 .txt | 业务句、换行；不自动判断哪些内容敏感 |
| Markdown .md/.markdown | 对完整源码替换，输出UTF-8 .md | front matter、HTML注释、链接地址和代码都在预览中；未选原文仍保留 |
| CSV/TSV | 按明确分隔符读写，保留文字行列；给可执行公式样式文本加单引号 | 引号内换行、列数、数字文本及单引号变化；用表格软件打开仍需核对 |
| XLSX/XLSM | 输出.xlsx，重建可见工作表/行/列中的值并保留受支持的业务数字格式，表名改成表1等 | 隐藏表行列、公式、宏、图片、图表、备注、链接和原属性不带入；数值缓存可能过时，工具不重算。可见公式无缓存则停止；`;;;`隐藏格式的单元格清除，条件格式、同色文字（含主题色、索引色）或未知显示规则拒绝 |
| PPTX | 输出.pptx，重建可见页文字及可编辑表格，分页重排 | 备注、隐藏页、图片、图表、动画、母版和原属性不带入。只有图片/图表的页会停止；长文本/大表需拆分。不能保留原设计 |
| PDF（含扫描件） | 按144dpi逐页渲染、像素框选，重建纯图像.pdf | 原文字层、附件、脚本、链接、表单、签名对象及原属性不带入，无法继续复制搜索文字；逐页人工查看，最多20页、总4000万像素，无OCR |
| DOCX | 重建文字/表格.docx，页眉页脚移入正文 | 图片、批注、修订、隐藏标记、链接及属性清除，版式重排；复杂对象拒绝 |
| PNG/JPEG/WebP | 人工框选后输出实色覆盖.png | 方向、元数据、框外像素；无OCR |

TXT/Markdown/CSV/TSV默认接受UTF-8及带BOM的UTF-16；GB18030需明确选择或在计划写`input_encoding`，不猜测编码。文本中的不可支持控制字符停止。

DOC/RTF/ODT→DOCX、XLS/ODS→XLSX、ODP→PPTX；PPT→纯图像PDF（逐页人工框选）采用兼容重建。ODF直接解析；旧二进制及RTF另需本机LibreOffice、私有配置和网络隔离。支持范围、停止条件、公式/版式变化集中见[兼容导入](compatibility.md)。不保留旧格式容器，不通过改扩展名转换。

PDF复检必须同时提供原PDF；图片同理。文本/表格/PPT使用`keep`声明关键保留句。PDF没有文字层，禁止用文字keep冒充保留验证，改查实际页面和框外像素。

## 表格中的数值与显示

XLSX/XLSM保留数值与受支持的格式：General、文本、固定长度零编号、常规小数和千分位、百分比、¥/￥/$金额；日期时间目前接受`yyyy-mm-dd`、`yyyy/mm/dd`、`mm-dd-yy`、`yyyy-mm-dd h:mm:ss`、`yyyy-mm-dd hh:mm:ss`及`h:mm`/`hh:mm`/`h:mm:ss`/`hh:mm:ss`。超过范围的科学计数、分数、多段或复杂自定义规则会停止，不静默转General。关键编号原本按文本存储时仍保留文字。

预览与保留项检查使用显示值，例如`15%`、`00123`；补选命中数字的显示值时，该单元格变为替换标记文字。默认保留数值的单元格仍可作为值使用，公式不会保留。显示保留不代表计算缓存一定正确，仍需打开副本对照。

旧XLS/ODS走兼容路线：支持的格式化数值按源文件可见显示缓存转成普通文字，普通数值尽量保持数值。这样可保留百分比、单位与编号读法，但不能当作保留了原数值类型或计算能力；条件显示、缺缓存及无法判断可见性时停止。

字体和背景的直接RGB、主题色、索引色会按工作簿解析后判断；色彩调整、图案填充或无法解释的颜色引用停止，不猜测可见性。
