# 执行踩坑

只记会改变以后动作的坑。症状、最早原因、正确动作、怎么验。细节例子留在 iteration，不把聊天当规范。

## 检查器绿了，人看不出比原来好

- 症状：改了一圈文案门、data-* 和检查器，用户第一眼仍觉得是工作台壳。
- 原因：先修检查器能抓住的词，首页还是绿条 CTA + 通用开箱卡。
- 动作：每一刀先改第一屏长什么样。考公第一眼必须是卷（题型条、题、提交）；计划第一眼必须是今晚时间表。检查器只锁已经看得见的合同，不为了过门再留一道假题。
- 验证：桌面/手机打开首页和计划，用图判断，不靠 CLI 摘要。

## 收侧栏当优化

- 症状：房间少了，看起来干净，内容变空。
- 原因：把空壳和「房间多」当成同一个问题。
- 动作：已选房间都留在侧栏。失败点是点进去没活，不是目录长。
- 验证：`check_exam_practice` / `check_finance_tonight` 拦 tonight_nav 藏房间；目视每个侧栏第一张卡是这个房间的活。

## 给人看的页写成「走查工作台」

- 症状：考公页左上角叫走查工作台。
- 原因：重编样例时 `--title` 用了内部外号，品牌名跟着走。
- 动作：给人打开的 HTML 必须用场景产品名，例如考公刷题工作台、月度记账工作台。禁止走查工作台、声明式工作台、测试页这类门牌。
- 验证：打开页看 `.brand-title` 和 `<title>`，必须是今晚这个场景的名字。

## 主动作挪到卷面后，手机第一屏丢了

- 症状：`evaluate` 报 `experience_contract_failed` / `primary_action_in_first_viewport`。
- 原因：收集器在 390×844 量主动作 `y < 844`。绿条「做这一题」很靠上；改成卷面「提交这题」后，题干折行、选项、开箱说明会把它顶出首屏。
- 动作：手机考公首页收掉大绿条；未作答不要占一行下一题；提交必须留在第一屏。空点提交只提示先选择，不能当崩溃。
- 验证：`check_exam_practice` 拦绿条 CTA；跑考公 evaluate。

## 专用卷面过不了 evaluate

- 症状：计划房判断题删掉后，收集器去点做题房，却还在找 `.starter-question`。
- 原因：验收脚本只认通用开箱卡；专用卷用 `data-exam-option` / 「对了」「错过了」。
- 动作：有专用卷就让收集器走卷面。不要为了过评测在计划房留一道假题。
- 验证：收集器源码含 `data-exam-item` 和「错过了」；考公 evaluate 通过。

## 场景 CSS 被后面的通用规则盖掉，页面横向溢出

- 症状：题型条还是折两行；计划表在手机里竖着拆字；`responsive_failed` / `no_overflow`。
- 原因：后写入的通用 CSS 覆盖了先前的 `nowrap`；grid 子项默认 `min-width: auto`，芯片把整页撑宽。
- 动作：场景覆盖写在通用规则之后，或提高选择器优先级。滚动条所在块和父级都设 `min-width: 0; max-width: 100%`。
- 验证：手机首页题型条单行可滑；页面无横向滚动；evaluate 响应式通过。

## 朗读没选声，英文词用中文声

- 症状：Mac 上中文像用英文默认声或 Ting-Ting compact 在念；点 apple 却把「苹果」也读进去，或用中文声读单词。
- 原因：`speechSynthesis` 不设 `voice`；语言只靠整段文字猜；词卡 `textContent` 带了中文注释。
- 动作：按语言挑默认声（中文 Google 普通话 / Xiaoxiao / Huihui；英文 Google US English / Samantha / Aria）。词卡用 `data-speak-lang` 锁语言，只读英文词。不调用 macOS `say`。无头 Chrome 列不出音色，听感要在本机真页上点。
- 验证：`check_exam_practice` 锁选声、compact、samantha/aria、`data-speak-lang`；本机点「听这题」和英文词卡。
