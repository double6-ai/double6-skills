# 班主任开箱内容

改班务、考勤或跟进种子时必读。首页主活动仍是今晚勾班务、记到/假/迟、跟进到人工发。不把教师工作台做成学校 OS。

来源：`build-professional-workbench` 教师案例的虚构世界写法（同一拨对象、事项像今晚会碰到的话、名册里有例外）。不吸收真名花名册、学籍号、真校名或 57 个栏目。

## 必须成立

- 开箱合成对象跨班务、考勤、跟进共用。考勤标题是合成代号（如 `小A`）；跟进标题点名其中至少一个代号；至少一条班务也点名这个代号。
- 至少一条今晚例外：考勤为「假」或「迟」，或跟进是今晚要处理的例外（如作业未交、请假）。
- 代号只许 `小A` 这类合成写法。禁止真名、真校、真学籍。

## 禁止

- 张雨桐一类像真学生的姓名
- 学籍号、`G2026…` 一类编号
- 实验小学、带地名的学校
- 把花名册、转学核办、收费公示做成开箱主内容
- 班务、考勤、跟进各编一拨人

改种子后跑 `python -B scripts/check_teacher_class.py`。
