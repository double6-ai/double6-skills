# 已提问题审查

用户指出过的产品问题不能只修一次。每条都要登记到 `review-invariants.json`，并由 `scripts/check_child_review_invariants.py` 反复检查。

内容真值仍走 `content-truth-review.md`。这里管的是**已经发生过的交互/入口/题量/题图/内容雷**，避免同一类承诺和页面再次对不上。

内容雷不要靠人工一题一题扫，也不要只扫儿童题。新题、改题或重建页面后，先跑 `check_content_mines.py`；儿童入口/题图/房间再跑本审查。排雷类型、例外和如何加一类新雷见 `content-mines.md`。

## 什么时候跑

改儿童乐园页面、题库、入口文案、房间或作答页之后必跑：

```bash
python -B scripts/check_child_review_invariants.py
```

发布门会核对本文件和检查器存在；活动测试会调用检查器。只看首页截图、或只跑旧通过项，不算已经审查。Playwright 字号/可点通过后，仍须按 `visual-self-review.md` 打开 PNG 目视作答页。

## 新增一条

1. 用用户原话写 `user_finding`，记下日期。
2. 写一个可判定的 `checker`，放进检查器。
3. 先让检查器在旧代码上失败，再改产品。
4. 审查范围要覆盖说这句话的那个页面：说明页、作答页、学科练一练，不能只查源码字符串。

禁止：聊天里修完就走；把“文件存在”“按钮能点”当成入口已通；用一升二冻结尾冒充宝宝 / 二升三 / 三升四已审。

## 当前沉淀

| 用户原话 | 必须成立 |
| --- | --- |
| 写着还有 5 题，却没有入口 | 答完后必须能继续做同组下一题；现在只出「下一题」，不再铺题名 |
| 每类只有一题 | 宝宝 / 二升三 / 三升四每个题型 6–10 题 |
| 长颈鹿找朋友，答案里又有自己 | `baby-math-02` 答案不是长颈鹿，选项里也没有 |
| 题图是猫，选项最好是图 | 题图是长颈鹿；选项有图片或 emoji |
| 今天三站盖住房子图 | 房间图和今天三站是两个区块 |
| 除一升二外按钮点不了 | overlay 作答页必须有 hero 兜底，不能再因缺图崩溃 |
| 页面不像给小朋友看 | 题面是能读出口的话；说明页只有故事和开始；作答页没有基础练习、知识点或掌握；近义/英语题图按词义，不能再是字母块 |
| 做完 3 次 6 题还出新题 | 一组 6 题做完必须停住；换站或换组前先确认 |
| 四档看不出大差异 | 宝宝 / 一升二 / 二升三 / 三升四首页标题、默认房间和主按钮必须不同 |
| 房间大图还是同一套女孩小屋 | 四档主图文件、哈希、房子形状、机位、场景必须都不同 |
| 答完铺一堆题名、故事和问题拆页、答案总在第一项、标题泄题、弟弟配大象 | 答完只出下一题；练一练开做前也只留当前一题；故事和问句同页；同组题答案不能全在第一项；作答页标题不能写出答案；声母题不能用「A和B」；题图不能是答案图；一组做完不得循环；数量图画被数物件 |
| 选项字母很大却被卡片切掉 | 短选项按卡片缩放，不能写死 136/168px |
| 已经一组连做，首页还写各一题 | 学段文案不得再写「各一题」 |
| 伙伴卡写着奥特曼，画的是原创勇士 | 可见文案用光之勇士；内部 id 可保留 |
| 是不是还需要狗狗说饿了、熊猫说饿了的图片 | 四种皮各有在等/好了两张图，哈希锁定；文案说饿了时不能还是一张笑脸 |
| 怪兽在远处晃，需要真的能看见怪兽 | 光之勇士在等图必须画出可见小兽，双人中景，不能只是脸部特写 |
| 房间还要更像这是我的 | 没写名字是「我的小花园」；写了是「乐乐的小花园」。门牌给家长写称呼 |
| 小朋友要的不是摆小素材 | 儿童首页不得再把摆件、拖动物件当成主活动 |
| 房间大图把今天三站挤出手机首屏 | 伙伴卡之后先是今天三站；房间只做门牌条跟在后面 |
| 一升二手机先是四格统计 | 儿童手机首页只留今天 n/3；星星徽章仍在侧栏和小卖部 |
