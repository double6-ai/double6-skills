# 内容真值与审稿门

这套门适用于题目、练习、测验、参考卡、行动卡、图表、计算器结果、AI 生成学习材料及其它会影响用户判断的可见内容。版式漂亮、按钮可点、社媒来源真实，都不能替代内容正确。

## 三种证据角色

- **真值依据**：决定题干、事实、答案、解析或安全边界。算术可用确定性计算；词义、科学、健康和课程事实使用与问题匹配的可靠来源；阅读题使用题内逐字证据。
- **呈现来源**：社媒、历史样例或设计系统只回答“如何显示和交互”，例如使用苹果 emoji、对象分组、短提示、单题流和答后解释。不得把受欢迎度或作者说法当作答案证据。
- **运行证据**：浏览器截图、DOM 语义、点击路径和可访问文本证明页面实际呈现了已核验合同，不能只证明按钮能返回预设的 `correct`。

## 每项内容的真值合同

制作或改写前，为每项内容登记：

1. `objective` 与适用人群；
2. 题干或行动提示；
3. 作答前会看见的刺激、图像和提示；
4. 选项或输入边界；
5. 独立 oracle：答案、推导、题内证据或可观察完成条件；
6. 答后解释；
7. 可访问语义；
8. 安全与家长边界；
9. 真值依据和呈现来源分别登记；
10. 独立审稿状态及未关闭 finding。

结构化合同当前使用 `double6_content_truth_v3`；审计器仍只读兼容历史 `v1`、`v2`，但新增或扩充内容不得回退。执行：

```bash
python -B scripts/audit_content_truth.py path/to/content-truth.json
```

## 通用失败条件

- 题干、图示、答案、解析或 aria 语义互相矛盾；
- 正确答案缺失、重复，或不在可选择/可输入范围内；
- 测验型内容在标题、图示、预先高亮、说明或装饰中泄露答案；
- 题目需要外部知识，却只有社媒呈现来源、作者宣称或模型自述；
- 屏外儿童行动缺少允许地点、停止条件、家长边界或隐私边界；
- 仍有 blocking/major finding，却把整体写成通过；
- 只看 contact sheet、缩略图或点击结果，没有核对全尺寸首屏与关键状态。

## 第三版定向扩充与低龄作答合同

批量扩充不能只检查“有题干、有答案”。每条新增内容还必须登记：

- `content_role`：逐错因纠正、新增迁移、主动产出或结构化屏外表达；
- `variation_values`：本题实际改变的目标、对象、位置、干扰、措辞或生活情境，不能只引用 atom 的抽象变式轴；
- `response_mode` 与 `interaction_contract`：单选、页内数字键盘、词块排序、田字格手写、字母卡、短语词块、家长口头观察或屏外家长观察；
- 逐错因纠正题必须且只能绑定一个 `misconception_ref`，并把错误探针映射到该错因，给出短小的 `remediation_next_action`；
- 新增迁移题必须登记 `transfer_axis`；
- 低龄内容不得把系统键盘当成默认作答方式；除非明确记录孩子具备键盘能力，否则“写汉字”用触控田字格、“拼英文”用唯一 ID 字母卡、“补句子”用词块、“朗读/复述”用家长现场观察；
- 手写画布必须拒绝空白提交，支持清空重写，写完后才显示对照字；没有人工或可信识别时只能记录完成和自我对照，禁止声称自动判字或学习掌握；
- 字母卡与词块必须分别绑定唯一内部 ID、正确组合和错误组合；重复字母用不同 ID，不能因标签相同而误禁用；
- 口头作答必须有 2–3 个题内可观察标准，家长确认前不得宣称答对，且不录音、不上传、不调用语音识别；
- 排序必须有唯一词块、正确顺序、包含同一组词块的错误探针，以及与正确答案不同的初始展示顺序；“重新排”后必须恢复该非答案顺序，不能把正确顺序直接摆在孩子面前；数字输入必须使用页内数字键盘；
- 结构化屏外表达必须有 2–3 个可观察标准，仍保持家长在场、无儿童媒体采集和明确停止条件。

缺少任何上述字段都应 fail closed。浏览器验收必须真实执行错误输入、清空/重排、正确输入和全部家长观察勾选；只检查预设 `data-result` 不算通过。

## 专项 oracle

- **算术与数量图**：初始量、变化量、结果量必须守恒；分步图每一步的 `before/change/after` 连续；屏幕中每个快照的对象数必须等于合同，而不是靠“看起来像”。
- **词义、图词与英语**：正确选项的 semantic 与目标词义一致；作答前不显示对应图片、中文释义或其它等价答案，除非明确标为 `guided_practice`。
- **承诺型视觉题**：标题、题干或提示只要出现“看图”“观察图”或“哪幅图”，实际作答页在提交前必须有与题意一致的可见语义图；说明页、卡片封面、隐藏 DOM 或只存在于答后解释里的图均不算。浏览器门逐题检查图片存在、语义绑定、非空可访问名称和实际尺寸，并确认庆祝动画等覆盖层不会残留到下一题。
- **分类与规律**：分类标准唯一、异类唯一；规律至少出现两轮，下一项由同一规则唯一决定。
- **短阅读**：答案证据逐字存在于题内文本；测验前不得把答案实体加亮。
- **古诗与文化**：题名、作者、采用文本、证据句、解释和版权状态可追踪；图像只辅助理解，不偷换文本含义。
- **屏外行动**：完成条件可观察但不采集儿童媒体；默认要求现场家长、允许地点、停止条件和“不确定就不碰/不做”的规则。

## 审稿与状态治理

结构审计、确定性 oracle、全尺寸视觉检查和关键交互必须全部通过，且 blocking/major 为零，才能写 `content_truth_passed`。任何语义矛盾都会使旧通过回执失效：保留旧文件作为历史证据，新增 superseding receipt 写明失效原因、受影响 SHA 和替代版本，不得静默覆盖或继续引用旧结论。

已有内容若没有真值合同，只能写 `legacy_structural_checks_only` 或 `truth_review_required`，不得追认成内容正确。儿童学习的进一步规则见 `education-rules.md` 和 `education-content-research-policy.md`。
