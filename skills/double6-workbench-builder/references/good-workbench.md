# 怎样叫一个好工作台

这是本 Skill 的产品验收合同。任何宿主按本文执行即可，不依赖特定 agent 产品，也不要求多 agent。北极星三层仍以项目 `README.md` 为准；本文把三层落成可判定的问题和禁做项。

做完一刀必须按本文看图，不能只看「做完了」。不知道的条目标 `unknown`，用调研补；补上之前不得假装已经知道。调研可以提出新方向，但必须先过项目 `references/optimize-execution-skill.md` 的方向闸，才能变成切片；不另开主题，不过闸不能动手。

## 一句定义

人打开它，是为了把今晚这份活做完，并且愿意把页留在眼前。不是为了参观一个叫「工作台」的壳。记录、导航、装饰、边界声明都是支撑，不能顶替做事。

好工作台像这个人已经在用的工具：记账像在记自己的钱，备考像在做自己的题。字段用他嘴里的词，第一屏就是他来干的那件事。内容丰富度是一等指标：已选房间都要在侧栏里，点进去都有能做的活。空壳才算失败，少开房间不算优化。记录表单只是残留，不能摊成「完整操作区」。制作器的话（内置内容、自有记录、查看内置示例、完整操作区、先从这里开始、可反复练习、小任务、可编辑模板、完成这一项）出现在使用者眼前，这一页就还没做成工作台。

## 先问谁在用

同一张页至少要过两关：使用者为什么打开，旁边的人为什么允许它留下来。

| 场景 | 使用者要的 | 旁边的人要的 | 常见做错 |
| --- | --- | --- | --- |
| 儿童学习 | 打开就能玩今晚三站；在乎的角色还在等他 | 孩子肯坐下、三站做完、门牌是自家称呼 | 布置房间、堆装饰、把摆件当玩 |
| 成人执行 | 打开就看见正在推进的几件事到哪了；今天该动的动手 | 自己能看见每件进展，不把没动作当成消失 | 记事本、空表、先填一条样本、每天只准推一件 |
| 备考 | 打开就做今晚这一组，题型分得清，当场看到对错 | 进度只表示练过，不是掌握，更不是上岸 | 总榜、冒充真题、保证上岸、把练习写成掌握、侧栏看起来像另一套表单 |
| 班主任 | 打开就看见今天的班务、考勤和待跟进，并能当场勾掉或记下 | 只用代号；家校消息仍是人工发 | 今晚只推一件；拖座位当主活动；自动发家长群；给学生贴标签；真名花名册；班务/考勤/跟进各编一拨人；开箱全是正常没有例外 |
| 减脂日常 | 打开就记下今天的体重、三餐和有没有练 | 数字是自己记的事实，不是减重成功；回来时能看见一句鼓励或暖心诗词 | 把小学「今晚勾组」套过来；保证瘦下来；页内假装跟练在播；把星星小狗扣过来；完全不做激励 |
| 销售跟进 | 打开就判断或跟今天这一家 | 自己看见跟了没有，消息仍是人工发 | 先记一条线索、空 CRM |
| 自媒体生产 | 打开就推今晚这一篇 | 自己看见推进到哪一步，发布仍是人工 | 先收下一条观察、空日历 |
| 个人一周 | 同时有日常、又有几件必须自己盯的真事（副业、装修、论文、搬家） | 每件都看得见进展；今天有动作的动手，没有动作的也不掉出视野 | 把一周记下来；每天只准推一件；面向「所有想管生活的人」 |
| 家庭今晚 | 打开就看见今晚谁做什么，能勾掉 | 对方靠当面说，不靠这页同步；不要真名和账号 | 周历空表；情侣游戏；爱心币；发给对方却假装已收到 |
| 月度记账 | 打开就记今晚这笔支出或收入，看见今日合计 | 合计只加自己填的数字；凭证能勾；税保持待专业处理；数据只在这台设备 | 空月结台；ERP 全流程；银行余额；已申报；自动报税；数据永不丢失 |
| 店铺订单 | 打开就处理今天这几单 | 库存只是带日期的手工快照；客服还要自己去平台回；页面不发货 | 空经营台；ERP 侧栏；实时库存；已发货；自动退款；连接店铺 |
| 研究结论 | 打开就写下今晚这条带出处的结论 | 没有出处就标缺口；未核验摘录不是事实；本页不发表 | 空资料库；无来源已证实；自动生成报告；已同步知识库 |

过不了「使用者为什么打开」，后面的视觉和激励都不算。

使用者和旁边的人要什么，从该场景社媒可见实践和已吸收矩阵来，由 agent 扮演这两种人看图判定。不要把「找到真实孩子/家长/客户来试用」当成验收门；也不要把点赞量写成他们愿意持续用。核心齐了就停：今晚那一件能做，愿意待和想回来达到上表最低线。换肖像、挪格子、加题、加第三套激励都不是核心。

## 四层，按顺序看

后一层再热闹，也顶替不了前一层。

1. **今晚那一件**：首页主活动是做这件事，且必须跟该场景证据走，不得把小学「今天三站 / 勾组」套到别的场景。儿童是今天三站。减脂日常是记下今天的体重、三餐和有没有练。班主任是今天的班务、考勤和待跟进同时看得见。家庭今晚是谁做饭、谁洗碗、要买什么，能勾掉；待当面说不是已发送。月度记账是打开就记今晚这笔，今日合计是自己填的数字相加，税不是已申报。店铺订单是打开就处理今天这几单，库存不是实时，客服不是已发送。研究结论是打开就写下今晚这条带出处的结论，缺出处就标缺口。考公是打开就做今天这一组题。销售、自媒体是今天那一项可观察动作。个人一周例外：首页先让人看见几件真事各自到哪了。
2. **愿意待**：人愿意把这一页留在眼前。房间、颜色、角色要像「我的」，不是后台表。文案说饿了/遇险，画面必须也是。
3. **想回来**：做完有攒的，没做完有在乎的角色还在等。不羞辱、不扣掌握、不加第三套货币。成人减脂不是关卡：每日一句鼓励或正向暖心诗词，近七日来过看得见。不是完全不需要激励。
4. **还能打开**：保存恢复、本机连续。部署和同步往后排。

## 判定问题

做完一刀，必须能用「是 / 否」回答。答不上来就是没验收。

1. 一个第一次打开的人，三十秒内能不能开始这个场景真正要做的事？（不一定是「一件」。班主任、个人一周、儿童三站都不是只推一件。）
2. 拿掉装饰和激励之后，主线还能不能讲完？
3. 文案承诺的东西，画面上是不是真的在？
4. 这个场景的人看完，会不会觉得今晚做成了，而不是被布置了一通？
5. 这次改动会不会让人更想打开，还是只让页面更满？
6. 每一个侧栏点进去，还有没有可做的事？只有标题加「查看内置示例详情」算失败。已选房间少了、靠收侧栏假装干净，也算失败。
7. 第一道题或第一张卡，这个人会不会认成自己的活？考公第一题是近义词、记账框写「数值 1」都算失败。

任一题答「否」或「说不清」，这一刀不能标完成。

走查时还必须写下**用户这轮没有点名的问题**。清单为空，说明你只在核对工单，没有在用这个人的眼睛看页。只修点名项、不自己找下一刀，这一轮迭代无效。

## 做好了长什么样

- 儿童首页：伙伴还在等、今天三站不用往下翻、房间一眼不同。门牌可以有称呼。连续打开三天，伙伴卡上三格有来过痕迹，第三天能感到「又见面了」，不是连续天数数字。
- 文案「肚子饿了」时，图是空碗；「怪兽在晃」时，卡片上能认出小兽。
- 答对有星、连击、三站奖励；答错只暖一句。庆祝马上消失。
- 数据只在这台设备。换电脑前能导出。

## 不算好工作台

- 记事本：主活动是填表、摆件、看统计。开箱第一句是「先记录一条」或「先填一张空表」。
- 空壳侧栏：导航看起来有复盘、审计、计划、素材，点进去没有可判断、可演算、可勾的内容。失败点是空，不是房间多。
- 收目录当优化：把已选房间从侧栏拿掉来显得干净。丰富度下降了，这一刀无效。
- 错身份的开箱：考公用小学生近义词，记账把收入支出叫成数值 1 / 数值 2。能点不等于像这个人的工作。
- 别人的账：开箱就把晚饭 29.90 写进流水。首页应是空账，让人自己记第一笔。
- 科目跳错题：卡上写片段主旨、三段论或工程行程，点「去做题」却落到做题房第一题或别的科。
- 申论只给提纲：素材房只能看提纲或「按这个改」填进残留表单，没有可写的问题、原因、对策。
- 同款皮：四档只换标题，房间还是同一张构图。
- 口头故事：文案说饿了，图还在笑。
- 布置房间：给孩子一堆不能玩的小素材，或把拖装饰当成主活动。
- 假装接上：没有真实响应却写成已接入。把本机勾选、草稿或 CSV 写成已经发到学校、家长群、平台或云端，也算假装接上。
- 邻域壳：把儿童三站、小卖部或别的场景首页套到当前今晚那一件上。
- 部署冒充产品：页面能打开，但不等于日常能用。
- 检查器壳：文案门和 data-* 都过了，第一眼仍是绿条加通用卡，不像今晚那件活。这一刀无效。
- 同色按钮当工作台：考公三扇门做成三颗一样的主色按钮，分不出行测卷、申论稿纸和面试计时。这一刀无效。
- 门牌外号：给人看的页写成走查工作台、声明式工作台。门牌必须是这个场景的产品名。

2026-08-18 的摆件/拖动就是「布置房间」。根因是把「这是我的」理解成装修，而不是「今晚这件事是我的」。

## 一刀怎么切

一次只改一个使用者、一个主活动、一个失败样例。动手前写清：

- 谁用，旁边的人是谁
- 今晚那一件是什么
- 对照上表哪一条
- 禁止做什么（尤其禁止布置房间）
- 怎样验收：看哪几张图、回答上面五问
- 沉进本 Skill 的位置（合同、检查器、运行时或审查规范）

不得在用户授权前打包、同步宿主、加第三批题或改冻结内容 SHA。

## 换场景时

健身、班主任、考公仍用本文。先填「谁在用」那一行，再切一刀。不要另写一套「好工作台」。场景特殊规则进该场景的 pack / 细则，不覆盖本文。
